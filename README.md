# 🔑 Твой ключ на чердаке

Бот-воронка для игропрактика Наташи Люлькиной.  
Платформа: **Max** (max.ru)

## Что делает бот

1. Пользователь пишет «ДОМ» (или /start)
2. Проходит 3-минутный обход «Дома Души» (3 вопроса)
3. Получает один из 27 уникальных результатов
4. Видит эффект незавершённости (2 закрытые комнаты)
5. Выбирает: «Комната Тела», «Отношений» или «Обе»
6. Получает персональное приглашение на бесплатную диагностику
7. Бронирует слот

## Быстрый старт

### 1. Регистрация бота в Max
- Найди @BotFather в Max
- Создай нового бота, получи токен
- Скопируй токен в `.env`

### 2. Установка
```bash
pip install -r requirements.txt
cp .env.example .env
# Отредактируй .env, вставь свой токен
```

### 3. Запуск локально
```bash
python bot.py
```

### 4. Деплой (например, Render.com)
- Залей код на GitHub
- Подключи репозиторий в Render
- Укажи переменные окружения
- Получи URL вида `https://tvoy-klyuch.onrender.com`

### 5. Webhook
```
GET https://api.max.ru/bot<TOKEN>/setWebhook?url=https://tvoy-klyuch.onrender.com/webhook
```

## Команды бота

| Команда | Действие |
|---------|----------|
| `ДОМ`, `/start`, `ключ` | Запуск обхода |
| Inline-кнопки | Ответы на вопросы |
| Текст после бронирования | Ручной ввод времени |

## Переменные окружения

| Переменная | Описание |
|------------|----------|
| `MAX_BOT_TOKEN` | Токен от @BotFather |
| `ADMIN_ID` | ID Наташи для уведомлений |
| `PORT` | Порт сервера |

## Логика результатов

Код = Фундамент(A/B/C) + Окно(A/B/C) + Чердак(A/B/C)

Всего 27 комбинаций. Каждая имеет уникальный текст в `RESULTS`.
